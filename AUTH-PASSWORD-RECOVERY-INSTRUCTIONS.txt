Komparse Assistant — récupération du mot de passe

Fichiers à remplacer dans le projet :
- web/app.js
- web/index.html

Fonctionnement :
1. L'utilisateur saisit son e-mail et clique sur « Mot de passe oublié ? ».
2. Le site demande à Supabase un lien de récupération, avec redirection vers l'application (mode=recovery).
3. Depuis le lien reçu par e-mail, l'utilisateur définit et confirme son nouveau mot de passe.
4. Après la mise à jour, l'utilisateur revient à son profil connecté.

Important — configuration Supabase :
Dans Authentication > URL Configuration, vérifier que la Redirect URL suivante est autorisée :
https://remicornerierrr-prog.github.io/komparse-assistant/?mode=recovery
Si la politique de redirection du projet utilise une liste exacte, ajouter cette URL exacte. Le lien de récupération par e-mail doit être activé dans les paramètres d'authentification / modèles d'e-mail Supabase.

Vérification locale :
node --check web\app.js

Après remplacement, commit et push :
git add web/app.js web/index.html
git commit -m "Add password recovery flow"
git push origin main
